# Firmware samples

This directory is reserved for legally obtained, explicitly consented firmware samples and their metadata. Preserve original dumps, record provenance, acquisition conditions, hashes, and read-only handling procedures. Do not commit proprietary firmware unless redistribution rights are clear.

The current read-only analysis report for the user-provided T460 SPI dump is
[t460-spi-dump.metadata.json](t460-spi-dump.metadata.json). It contains only
metadata and hashes, not firmware bytes. The FTPR Code Partition Directory
inventory is [t460-ftpr-cpd.metadata.json](t460-ftpr-cpd.metadata.json).
